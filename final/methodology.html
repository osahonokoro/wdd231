System Circuit Architecture

Circuit Components Overview

🖥️ Central Processing
  • Raspberry Pi 4 — Runs the dashboard and ML models
  • ESP32 Microcontroller — Sensor acquisition and preprocessing
  • Modbus TCP/IP — Network communication between units
  • Python Dashboard — Real-time data visualization
📡 Sensor Network
  • DS18B20 — Digital temperature sensor (±0.5°C accuracy)
  • DS495 Ammonia Sensor — UART communication, RS-485 compatible
  • pH Probe — Analog voltage input, continuous monitoring
  • DO Sensor — Electrochemical probe, galvanic membrane
🔌 Control & Actuation
  • 4-Channel Relay Module — GPIO-controlled switching
  • Channel 1 — Water pump control (0.37 kW, 2200 L/h)
  • Channel 2 — UV sterilizer control (40W, 99.9% sterilization)
  • Channel 3/4 — Backup/emergency controls
🔋 Power Management
  • 3.3V Regulated Supply — ESP32 and sensors
  • 5V Supply — Relay coil voltage
  • Flyback Diodes — Relay spike protection
  • Pull-up Resistors — Signal conditioning

Research Approach

This study integrates hardware design, machine learning, and energy optimization to deliver an intelligent aquaculture monitoring system with predictive capabilities.

🏗️ Three-Layer System Architecture

Sensor Layer
  • DS18B20 — Temperature monitoring (-55°C to +125°C)
  • DS495 Ammonia — UART communication, 0-100ppm range
  • pH Probe — Acidity/alkalinity measurement (0-14 pH)
  • DO Sensor — Dissolved oxygen tracking (0-20 mg/L)
Processing Layer
  • ESP32 — Data acquisition & preprocessing (dual-core)
  • Raspberry Pi 4 — ML execution & central control (4GB RAM)
  • Modbus TCP/IP — Industrial communication protocol
  • Real-time Clock — Time synchronization across sensors
Decision & Visualization Layer
  • Web Dashboard — Real-time monitoring (HTML/CSS/JavaScript)
  • Automated Control — Filtration/UV activation based on ML predictions
  • Data Logging — Performance analytics and historical trends
  • Alert System — Email/SMS notifications for critical conditions

⚡ Energy Optimization Strategy

Energy Calculation Formula: E = P × D × t

  • E: Energy consumed (kWh/day)
  • P: Power rating (kW)
  • D: Duty cycle (fraction of active time)
  • t: Total operational time (24 hours)
