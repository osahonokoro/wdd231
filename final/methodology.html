Methodology

The methodology integrates IoT sensors, machine learning models, and control logic to create an intelligent aquaculture filtration system. Sensor data is collected, processed, and analyzed to predict water quality states, which then guide energy-efficient control of filtration and UV sterilization.

Mathematical Model

The predictive function is expressed as:

y = f(T, pH, NH₃, DO)

where T is temperature, pH is acidity, NH₃ is ammonia concentration, and DO is dissolved oxygen. The output y represents the predicted water quality state.

Energy consumption is modeled as:

E = αF + βU

where F is the filtration duty cycle, U is the UV sterilization duty cycle, and α, β are scaling coefficients. The optimization objective is to minimize total energy use while keeping water quality within safe thresholds.

Algorithmic Implementation

The mathematical model was translated into a step-by-step algorithm implemented in Python on a Raspberry Pi 4. The algorithm performs the following:

  1. Initialize system and load trained ML model.
  2. Acquire sensor readings (temperature, pH, ammonia, DO).
  3. Preprocess data (normalize, filter noise).
  4. Predict water quality state using ML model.
  5. Apply decision logic:
    • Safe → minimal filtration, UV off.
    • Moderate → medium filtration, partial UV.
    • Hazardous → full filtration and UV sterilization.
  6. Adjust duty cycles proportionally using fuzzy logic.
  7. Log data and control actions to the web dashboard.

This ensures proportional responses rather than binary ON/OFF control, improving both efficiency and stability.

System Flow

Sensors → Machine Learning Model → Prediction → Control Logic → Filtration/UV → Web Dashboard
