System Architecture & Methodology

Technical implementation of an IoT-enabled aquaculture monitoring system that integrates sensor networks, control automation, and data-driven decision-making.

System Circuit Architecture

Circuit components overview

🖥️ Central processing
  • Raspberry Pi 4 — Runs the dashboard and ML models.
  • ESP32 microcontroller — Sensor acquisition and preprocessing.
  • Modbus TCP/IP — Network communication between units.
📡 Sensor network
  • DS18B20 — Digital temperature sensor.
  • DS495 ammonia sensor — UART communication.
  • pH probe — Analog voltage input.
  • DO sensor — Electrochemical probe.
🔌 Control & actuation
  • 4-channel relay module — GPIO-controlled switching.
  • Channel 1 — Water pump control.
  • Channel 2 — UV sterilizer control.
  • Channel 3/4 — Backup/emergency controls.
🔋 Power management
  • 3.3V regulated supply — ESP32 and sensors.
  • 5V supply — Relay coil voltage.
  • Flyback diodes — Relay spike protection.
  • Pull-up resistors — Signal conditioning.

Research approach

This study integrates hardware design, machine learning, and energy optimization to deliver an intelligent aquaculture monitoring system.

🏗️ Three-layer system architecture

Sensor layer
  • DS18B20 — Temperature monitoring
  • DS495 ammonia — UART communication
  • pH probe — Acidity/alkalinity measurement
  • DO sensor — Dissolved oxygen tracking
Processing layer
  • ESP32 — Data acquisition & preprocessing
  • Raspberry Pi 4 — ML execution & central control
  • Modbus TCP/IP — Communication protocol
Decision & visualization layer
  • Python Tkinter dashboard — Real-time monitoring
  • Automated control — Filtration/UV activation
  • Data logging — Performance analytics

⚡ Energy optimization strategy

Energy calculation: E = P × D × t

  • E: Energy consumed (kWh/day)
  • P: Power rating (kW)
  • D: Duty cycle (fraction of active time)
  • t: Total operational time (24 hours)
Continuous operation

100% duty cycle = 10.0 kWh/day

Predictive control

50% duty cycle = 5.1 kWh/day (49% reduction)

Aggressive optimization

30% pump + 50% UV duty = 3.3 kWh/day (67% reduction)
