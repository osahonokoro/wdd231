Circuit Components Overview

🖥️ Central Processing Unit
  • Raspberry Pi 4 - Main controller running ML models and dashboard
  • ESP32 Microcontroller - Sensor data acquisition and preprocessing
  • Modbus TCP/IP - Communication protocol between units
📡 Sensor Network
  • DS18B20 - Digital temperature sensor (GPIO 14 with 4.7kΩ pull-up)
  • DS495 Ammonia Sensor - UART communication (TX to GPIO 2)
  • pH Sensor - Analog voltage output (ESP32 A0 pin)
  • DO Sensor - Electrochemical probe (ESP32 A1 pin)
🔌 Control & Actuation
  • 4-Channel Relay Module - GPIO-controlled switching
  • Channel 1 - Water pump control (GPIO 17)
  • Channel 2 - UV sterilizer control (GPIO 18)
  • Channel 3/4 - Backup/emergency controls
🔋 Power Management
  • 3.3V Regulated Supply - ESP32 and sensor power
  • 5V Supply - Relay module coil voltage
  • Flyback Diodes - Protection against relay coil spikes
  • Pull-up Resistors - Digital signal conditioning

Research Approach

This study employed a comprehensive methodology integrating hardware design, machine learning, and energy optimization strategies to develop an intelligent aquaculture monitoring system.

🏗️ Three-Layer System Architecture

Sensor Layer
  • DS18B20 - Temperature monitoring
  • DS495 Ammonia Sensor - UART communication
  • pH Probe - Acidity/alkalinity measurement
  • DO Sensor - Dissolved oxygen tracking
Processing Layer
  • ESP32 Microcontroller - Data acquisition & preprocessing
  • Raspberry Pi 4 - ML model execution & central control
  • Modbus TCP/IP - Communication protocol
Decision & Visualization Layer
  • Python Tkinter Dashboard - Real-time monitoring
  • Automated Control System - Filtration/UV activation
  • Data Logging - Performance analytics

⚡ Energy Optimization Strategy

Energy Calculation: E = P × D × t

  • E: Energy consumed (kWh/day)
  • P: Power rating (kW)
  • D: Duty cycle (fraction of active time)
  • t: Total operational time (24 hours)
Continuous Operation

100% duty cycle = 10.0 kWh/day

Predictive Control

50% duty cycle = 5.1 kWh/day (49% reduction)

Aggressive Optimization

30% pump + 50% UV duty = 3.3 kWh/day (67% reduction)
